# Documentação do Tabeleão

- `arquitetura/`: base funcional e registros técnicos da arquitetura.
  - `arquitetura/ENDURECIMENTO.md`: controles de segurança, sessão, banco e operação do piloto.
  - `arquitetura/ANALISE_DOCUMENTAL_V2.md`: proposta de caso persistente, chat e fila documental.
- `operacao/`: instruções destinadas à administração local do sistema.
  - `operacao/AMBIENTE_VM.md`: sistema operacional, recursos detectados e divergências da VM do piloto.
- `planejamento/`: etapas, checkpoints e continuidade do projeto.

Documentos jurídicos e arquivos operacionais não devem ser armazenados nesta pasta.

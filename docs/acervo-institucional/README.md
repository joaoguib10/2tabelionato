# Acervo institucional

Cópias dos documentos institucionais aprovados, prontos, liberados e classificados como públicos no sistema da VM, exportadas em 19/11/2026. O diretório facilita migrar a instalação e conferir o acervo versionado.

Inclui documentos normativos e orientações/checklists institucionais. Não inclui anexos da aba Análise, banco de dados, credenciais ou configurações da VM. O arquivo `MANIFESTO.tsv` registra título, nome original, nome versionado, SHA-256 e tamanho de cada arquivo.

Os arquivos são uma fotografia do acervo na data da exportação. Inclusões futuras feitas pela interface não são enviadas automaticamente ao GitHub; devem ser exportadas e revisadas antes de um novo commit.
